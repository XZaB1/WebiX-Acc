# WebiX-Acc

Полноценная реализация авторизации на основе JWT-токенов: клиентская часть (страница входа) и серверная логика.

## О проекте

Пример страницы профиля пользователя на Webix — вкладка с информацией о человеке в стиле социальной сети продажников: достижения в продажах, метрики эффективности и визуализация результатов.

## Возможности

- Вкладка (TabView) с профилем человека и метриками

- Отображение данных о продажах и эффективности

- Визуализация показателей (таблицы, графики, карточки)

- Адаптивная вёрстка под разные экраны

- Компонентная структура на основе Webix UI

## Стек

**Webix:** — JavaScript UI-библиотека
**JavaScript:** HTML / CSS

##  Идея
Страница собирается как набор вкладок: основная информация о сотруднике, его показатели продаж, графики эффективности и достижения. Webix позволяет быстро комбинировать готовые виджеты в единый интерфейс без написания большого объёма HTML/CSS вручную.
